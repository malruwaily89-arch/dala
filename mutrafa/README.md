# مُترَفة — نظام الحجوزات والعربون لصالونات التجميل

منصة حجز وعربون لصالونات التجميل: صفحة حجز خاصة بكل صالون على `mutrafa.d-alal.com/{slug}`،
عربون إلكتروني يمنع الغياب، تذكيرات واتساب، وتقارير تختلف حسب الباقة.

> هذا المشروع مستقل عن تطبيق "دلال" في جذر المستودع، ولا يشاركه أي كود أو قاعدة بيانات.

## التقنيات

- Next.js 16 (App Router) + React 19 + Tailwind CSS 4
- PostgreSQL + Prisma 6 (القيود المتقدمة في migrations يدوية)
- TypeScript صارم، اختبارات بـ `node:test`، تحقق المدخلات بـ zod

## التشغيل المحلي

```bash
cp .env.example .env          # عدّلي DATABASE_URL
npm install
npx prisma migrate deploy     # إنشاء الجداول (من migrations)
npm run db:seed               # بيانات تجريبية واقعية لكل باقة
npm run dev                   # http://localhost:3000
```

## الدفع

- `PAYMENT_MODE=sandbox` (الافتراضي): صفحة دفع تجريبية داخل الموقع لا تُحصّل أي مبلغ. تمرّ عبر نفس منطق التأكيد الذي يستخدمه الدفع الحقيقي.
- في الإنتاج يُمنع الوضع التجريبي إلا بـ `ALLOW_SANDBOX_PAYMENTS=true`.
- `PAYMENT_MODE=moyasar`: إنشاء فاتورة عبر Moyasar، وتأكيد الدفع عبر webhook على
  `https://<نطاقك>/api/payments/moyasar/webhook` مع `MOYASAR_WEBHOOK_SECRET`.
  **تنبيه**: تكامل Moyasar مبني على توثيقهم العام ولم يُختبر مع حساب حقيقي بعد — جرّبيه بمفاتيح sandbox أولاً.

## واتساب

- بدون `WHATSAPP_ACCESS_TOKEN` تُسجَّل الرسائل بحالة `simulated` ولا تُرسل.
- لكل صالون: أدخلي **معرّف رقم الهاتف** (Phone number ID) من إعدادات الصالون.
- Webhook: `https://<نطاقك>/api/whatsapp/webhook`، مع `WHATSAPP_VERIFY_TOKEN` و`WHATSAPP_APP_SECRET`.
  الرسائل الواردة تُتحقق بتوقيع Meta، وتُرد آلياً (1 = رابط الحجز، 2 = استفسار).
- في الإنتاج يُرفض أي طلب webhook بلا `WHATSAPP_APP_SECRET`.

## المهام المجدولة

يجب استدعاء `GET /api/cron/jobs` كل 15 دقيقة تقريباً من أي مجدول خارجي (cron-job.org، Netlify Scheduled Functions…)
مع الترويسة `Authorization: Bearer <CRON_SECRET>`. تقوم بـ:
- تحرير الحجوزات التي انتهت مهلة عربونها (ساعتان).
- إرسال تذكير قبل الموعد بـ 24 ساعة (مرة واحدة لكل حجز).

## قاعدة البيانات

- `prisma/schema.prisma`: كل الجداول، المبالغ بالهللة، الأوقات UTC، عزل المستأجرين بـ `salonId`.
- `migrations/…_appointment_no_overlap`: **قيد EXCLUDE** يمنع تعارض موعدين نشطين على نفس الموظفة
  حتى مع الطلبات المتزامنة. يُختبر في `tests/integration.test.ts`.

## ما الذي لم يُنفَّذ بعد

- استعادة كلمة المرور والتحقق من البريد، وحد محاولات تسجيل الدخول.
- الاشتراك السنوي: الخصم السنوي غير محدد في الموقع، فلم يُفعَّل.
- الفاتورة الضريبية (معلنة "قريباً" في الموقع).
- إلغاء العميلة عبر رابط الحجز فقط؛ الأفضل إضافة تحقق برقم الجوال.
- نصوص الشروط والخصوصية **مسودات** وتحتاج مراجعة قانونية قبل الإطلاق.
- شعار الصالون ورفع الصور.
- اختبار بوابة Moyasar والواتساب بحسابات حقيقية.
