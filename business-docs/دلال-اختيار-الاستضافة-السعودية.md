# اختيار استضافة دلال داخل السعودية

## القرار المقترح

لا ننقل Production قبل قياس الأداء والنسخ والاستعادة على بيئة Staging. الخيار الأول للاختبار هو **Oracle Cloud Infrastructure في الرياض** لأنه يقدم مناطق داخل المملكة ويعطي قيمة تقنية جيدة لمكدس Next.js + PostgreSQL + Docker + Caddy. الخيار المحلي الأسهل تشغيلاً هو **Cloud.net.sa** إذا كانت الأولوية للدعم المحلي وSLA واضح.

لم يتم إنشاء حساب مدفوع أو نقل أي خدمة.

## المقارنة الأولية

| الخيار | الموقع | تقدير أولي | المزايا | الملاحظات |
|---|---|---:|---|---|
| OCI Riyadh | الرياض | نحو 180–190 ر.س/شهر لـ 2 OCPU و8GB و100GB قبل النسخ والضريبة | مرونة عالية، Docker وPostgreSQL، قابلية بناء تعافٍ بين الرياض وجدة | يحتاج إدارة Linux ونسخ ومراقبة ذاتية |
| Cloud.net.sa | الرياض/جدة | من نحو 288 ر.س/شهر للخطة الأساسية، ونحو 575 ر.س/شهر لخطة 2 vCPU و4GB بحسب الأسعار المنشورة | دعم محلي، مراقبة، SLA محلي، نسخ احتياطي متاح | يجب طلب عرض مكتوب يوضح مدة أسعار النسخ وشروط SLA |
| Google Cloud Dammam | الدمام `me-central2` | حسب الاستهلاك وعبر CNTXT للعملاء ذوي الفوترة السعودية | خدمات مدارة وتوسع قوي وبيانات داخل المملكة | أعقد في التشغيل والتكلفة من احتياج الإطلاق الحالي |
| AWS Bahrain | البحرين | حسب الاستهلاك | منظومة واسعة وخبرة عالمية | خارج المملكة، ولا يعطي أفضلية تكلفة واضحة لدلال حالياً |

الأرقام تقديرية للمقارنة وليست عرضاً تعاقدياً. يجب إعادة تسعيرها عند تثبيت حجم الزيارات، التخزين، النسخ، ورسائل WhatsApp.

## خطة التنفيذ الآمنة

1. إنشاء OCI Riyadh Staging منفصل، دون لمس VPS الحالي أو خدماته الأخرى.
2. تشغيل نسخة Docker من التطبيق وقاعدة PostgreSQL ببيانات اختبارية غير حساسة.
3. قياس زمن الاستجابة من الرياض وجدة والدمام، واختبار الضغط والنسخ والاستعادة.
4. تفعيل نسخ يومية ونسخة أسبوعية خارجية، مع اختبار استعادة شهري.
5. اتخاذ قرار النقل فقط بعد مقارنة التكلفة الفعلية ونتائج الاختبارات.
