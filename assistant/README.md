# مساعد واتساب الشخصي

خدمة صغيرة تربط رقم واتساب (WhatsApp Cloud API) بـ Claude. ترد على رقم صاحبها فقط، وتحفظ أي ملف يُرسل لها داخل مجلد على السيرفر (`inbox/<التاريخ>/`).

يقدر المساعد: يعرض ملفات المجلد، يقرأ النصوص وPDF والصور، يقرأ ملفات Excel ويعدّل عليها ويضيف لها صفوفاً (مع نسخة أصلية تلقائية في `.backups/`)، يحفظ ملاحظات نصية، يرسل ملفاً من المجلد على الواتساب، ويبحث في الإنترنت. وهو محاسب كذلك (قيود، قوائم مالية، ضريبة القيمة المضافة، زكاة). لا يقدر يكتب أو يقرأ خارج المجلد.

## التشغيل على السيرفر

1. أضف في DNS سجل A باسم `agent` يشير إلى IP السيرفر.
2. على السيرفر:

```bash
cd ~/dala && git pull && ./assistant/setup.sh
```

السكربت يطلب المفاتيح السرية فقط، ثم يبني الخدمة ويشغّلها، ويضيف `agent.d-alal.com` إلى Caddy (مع نسخة احتياطية وتحقق قبل التطبيق، وبدون إيقاف n8n)، ويربط الـ webhook في Meta. آمن إذا شغلته أكثر من مرة.

## شخصية المساعد

اكتب تعليماتك في `state/prompt.md` ثم `docker compose restart`. تغيير التعليمات يبدأ محادثة جديدة تلقائياً، والقديمة تُحفظ في `state/`.

أرسل `/جديد` في الواتساب لبدء محادثة جديدة في أي وقت.

## التطوير

```bash
npm install
npm test
```
