# مساعد واتساب الشخصي

خدمة صغيرة تربط رقم واتساب (WhatsApp Cloud API) بـ Claude. ترد على رقم صاحبها فقط، وتحفظ أي ملف يُرسل لها داخل مجلد على السيرفر (`inbox/<التاريخ>/`) مع بصمة SHA-256 وسطر في `سجل الوارد.csv`، والملف المكرر لا يُحفظ مرتين.

يقدر المساعد: يعرض ملفات المجلد، يقرأ النصوص وPDF والصور، ينسخ الملفات لمجلدات التصنيف مع إبقاء الأصل، يقرأ ملفات Excel ويعدّل عليها ويضيف لها صفوفاً (مع نسخة أصلية تلقائية في `.backups/`)، يحفظ ملاحظات نصية، يرسل ملفاً من المجلد على الواتساب، ويبحث في الإنترنت. لا يقدر يحذف أو يكتب أو يقرأ خارج المجلد.

## النموذج والتكلفة

- يعمل افتراضياً على Claude Haiku 5.5 (`AGENT_MODEL`).
- إذا احتاجت مهمة نموذجاً أقوى يطلب الموافقة أولاً، ولا يشغّل Sonnet 5.5 أو Opus 5.5 إلا إذا رد صاحبه برسالة تبدأ بـ «موافق». يبقى النموذج الأقوى حتى تنتهي المهمة أو 30 دقيقة، ثم يرجع للأساسي.
- عدّاد تقديري للمصروف الشهري مقابل `MONTHLY_BUDGET_SAR` (افتراضياً 300 ريال): تنبيه على الواتساب عند 70% و90%، وإيقاف الطلبات عند بلوغ السقف.

## التشغيل على السيرفر

1. أضف في DNS سجل A باسم `agent` يشير إلى IP السيرفر.
2. على السيرفر:

```bash
cd ~/dala && git pull && ./assistant/setup.sh
```

السكربت يطلب المفاتيح السرية فقط، ثم يبني الخدمة ويشغّلها، ويضيف `agent.d-alal.com` إلى Caddy (مع نسخة احتياطية وتحقق قبل التطبيق، وبدون إيقاف n8n)، ويربط الـ webhook في Meta. آمن إذا شغلته أكثر من مرة.

## مزامنة المجلد مع اللابتوب

ثبّت Syncthing على اللابتوب، وانسخ معرّف الجهاز (Actions ← Show ID)، ثم على السيرفر:

```bash
~/dala/assistant/sync-setup.sh <معرّف-اللابتوب>
```

بعدها وافق في Syncthing على اللابتوب على إضافة الجهاز `assistant-vps` وعلى مشاركة مجلد «ملفات المساعد».

## شخصية المساعد

اكتب تعليماتك في `state/prompt.md` ثم `docker compose restart`. تغيير التعليمات يبدأ محادثة جديدة تلقائياً، والقديمة تُحفظ في `state/`.

أرسل `/جديد` في الواتساب لبدء محادثة جديدة في أي وقت.
