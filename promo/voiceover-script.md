# نص التعليق الصوتي — مُترفة (45 ثانية)

نبرة: أنثوية دافئة وواثقة، لهجة خليجية بيضاء، إيقاع سريع خفيف. نطق الاسم: مُتْرَفة (mut-ra-fa).

| الوقت | النص |
|---|---|
| 0:00–0:06 | كم مرة جاتك عميلة وما حضرت؟ وكم انشغلت موظفاتك بالرد على الرسائل؟ |
| 0:06–0:12 | مع مُترفة، الرد يصير تلقائي على واتساب، وكل خطوات الحجز تتم بدون تدخل الموظفة. |
| 0:12–0:27 | العميلة تراسلك، فيوصلها رابط صالونك تلقائياً. تسجّل اسمها وجوالها، وتختار الخدمة واليوم والوقت، وتدفع العربون… والموعد يتأكد فوراً. |
| 0:27–0:34 | ولكل موظفة جدولها الخاص، فيبقى الترتيب محفوظ، وما يضيع وقت، وما يتعارض موعد. |
| 0:34–0:40 | جرّبي مُترفة مجاناً أربعة عشر يوماً… بلا بطاقة بنكية. |
| 0:40–0:45 | مُترفة… اشتركي الآن. |
