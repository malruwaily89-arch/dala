# مقطع جمع المهتمين — مُتْرَفة (قبل الإطلاق)

| البند | التفاصيل |
|---|---|
| الملفات | `out/mutrafa-lead-9x16-hookA-silent.mp4` و `out/mutrafa-lead-9x16-hookB-silent.mp4` |
| المواصفات | 1080×1920 (9:16)، 30fps، 40 ثانية، **بدون أي مسار صوتي** |
| الجمهور | مستقلات بوثيقة عمل حر + صالونات |
| الهدف | جمع ردود «مهتمة / غير مهتمة» لإشعار المهتمات عند الإطلاق الرسمي |
| ممنوع في المقطع | أي رابط أو رقم أو حساب تواصل، وأي سعر أو عرض |

## الفرق بين النسختين (أول 3 ثوانٍ فقط)

| النسخة | الخطاف | متى تستخدمها |
|---|---|---|
| A (ألم) | «كم رسالة حجز تنتظرك… وإيدك على الشغل؟» | البداية الموصى بها: تلمس الألم وتوقف التمرير |
| B (وعد) | «عميلتك تحجز وتدفع العربون… وأنتِ مكمّلة شغلك» | للصالونات الباحثة عن حل |

للاختبار: أرسل A لمجموعة صغيرة وB لمجموعة مماثلة، وقارن نسبة الردود.

## تسلسل المقطع

| الوقت | المشهد |
|---|---|
| 0–3 | الخطاف (A أو B) |
| 3–6 | الشغل لا يتوقف والرسائل تتراكم |
| 6–9 | هوية مُترفة: «حجوزات الجمال… تمشي لوحدها» |
| 9–25 | خطوات آلية: رد واتساب، رابط حجز وبيانات، اختيار الموعد، دفع العربون، تثبيت الموعد |
| 25–29 | المستقلة بوثيقة عمل حر: «رابطك الخاص يحجز عنك» |
| 29–33 | الصالون: «لكل موظفة جدول مستقل» |
| 33–40 | «هل أنتِ مهتمة؟ ردّي علينا بكلمة» مع بطاقتي **مهتمة** و**غير مهتمة**، ووعد «نخبرك عند الإطلاق الرسمي» |

## ملاحظات للنشر

- الرد يكون في نفس المحادثة التي أُرسل فيها المقطع، فلا حاجة لرابط داخله.
- اكتب مع المقطع رسالة نصية قصيرة تكرر الطلب: «اكتبي: مهتمة أو غير مهتمة».
- أسماء الصالون والعميلات والخدمات داخل الهاتف أمثلة توضيحية فقط.
- المقطع لا يعد بعروض أو أسعار أو تجربة مجانية، لأن المشروع لم يُطلق رسمياً.

## إعادة التوليد

`./build_lead.sh` (يرسم الإطارات من `lead.html` ويرمّز النسختين). خطاف B يُختار بالرابط `lead.html#B`.
